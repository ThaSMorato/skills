## Decisions and remaining evidence

- Markdown relative links are the interoperable default; established project conventions win.
- Report storage keeps metadata and counts only; absent paths are reported, never guessed. CLAUDE_PLUGIN_DATA is used only when supplied; ordinary Bash tool commands do not automatically inherit it. `THASMORATO_REPORTS_FILE` gives both harnesses one explicit shared location.
- Existing project doc layouts are read as legacy inputs. Migration requires a reviewed mapping before moves/deletions.
- Structural cross-stage hooks are not installed: menu flags and tool names do not prove owner intent. The stop rule is instruction/lint, not a security barrier.
- Live Claude/Codex spike, discovery accuracy on multiple models, UI/signifier/product-thinking real-use outcomes and cost/latency comparison remain release evidence to collect. This is why the manifest is beta, not stable.
