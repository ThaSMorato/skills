# templates/

**Canonical skeletons** per doc (`requirements-brief`, `prd`, `hld`, `fdd`, `adr`, `context`, `guidelines`). An agent **fills** the skeleton instead of inventing structure.

Triple duty: (a) generation **scaffold**, (b) **handoff anchor** between isolated agents (known sections), (c) **gate/review checklist**.

Rules: distilled from the author's vault notes but **self-contained** (no `[[links]]`); sections marked **required × optional**; the agent **prunes + renumbers** what doesn't apply; a skeleton = headers + one line of intent per section, **not** a heavy example.
