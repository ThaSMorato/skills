# skills/

**Model-invoked** skills (or interactive via a wrapper). They run in the **main context**, so they talk to the user live — use them for anything HITL (interview, gates) and for reusable primitives (glossary, seams, the 3-Es gate).

When it's skill × command × agent: see [`docs/anatomy/plugin-anatomy.md`](../docs/anatomy/plugin-anatomy.md). How to write one: [`docs/anatomy/skill-anatomy.md`](../docs/anatomy/skill-anatomy.md).
